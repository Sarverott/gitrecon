# [GitRecon][github project repo] - tool for software recon and technical oriented OSINT

gitrecon explores, recognizes and keeps listening to GitHub activity of users,
organizations, repositories and projects. It collects what happens into an append-only
raw buffer, maps who touches what, concludes labels for what is happening, writes its
findings into a shared map dataset, and can draft articles from summaries of the data.
