# a12y numeronym

> A word shortened to first letter, length, last letter: `workflows` -> `w9s`.

## What it is

Words colliding on the same numeronym get an index (`cross` -> `c5s`, `codes` -> `c5s1`), kept in a `Glossary`. Words not bounded by ASCII letters get a hex form `0-<first>-<len>-<last>`.

## Where

`gitrecon.text.a12y` (`a12y_key`, `Glossary`, `paratangle` checksums).

## Relations

Names directories of the [[user-namespace]]; builds the glossary of a [[rat-script]].
