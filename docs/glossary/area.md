# Area

> A top-level folder of the map with one kind of data and its own path scheme.

## What it is

`dnstrees`, `ip-address-records`, `host-unions`, `user-namespace`, `data-heuristicality`, `store-areas`, `posix-path-patterns`, `federationverse`. Each area may carry descriptors: `.index.json` (recursive listing, written by `reindex()`), `.omnis.toml` (checksums), `.about.md` (summary).

## Where

`MapDataset.areas()`, `ensure_area(name)`; layout described in the dataset's `README.md`.

## Relations

Parts of the [[atlas]].
