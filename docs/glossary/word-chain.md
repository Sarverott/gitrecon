# Word-chain

> A sentence as tokens, with every symbol spelled out as an uppercase word.

## What it is

`Run: task 2` -> `run DWUKROP task DWA`. Two tables: the first, English one (`COMMA`, `BRACKETSTART`) and the current Polish one (`PRZECINEK`, `STARTNAWIAS`, digits spelled too).

## Where

`gitrecon.text.tokenizer` (`sentence_prep`, `sentence_prep_legacy`, `text_to_tokenchain_sentences`). CLI: `gitrecon text tokens URL`.

## Relations

Input of a [[rat-script]].
