# Reading text

On this repository itself (no network needed):

- `parse_commit(message)`, `read_commits(path)`, `summarize_commits`, `commit_labels` - commit messages as records
- `find_requirements(text)` - sentences with MUST / SHOULD / MAY and their level
- `translate.translate(text, "en", "pl")` - offline translation, when the `translate` extra and a package are installed

```sh
task launch
task run
```
